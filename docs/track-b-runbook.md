# Трек B — рабочий регламент прогона

**Решение владельца 2026-08-02:** трек B (качество) идёт первым, до теста спроса.
Основание: образцы для трека A всё равно рождаются здесь, а лендинг без образцов
меряет обложку, а не продукт.

Цель трека: получить честный ответ на один вопрос —
**держим ли мы узнаваемого героя на всех разворотах при строгом толковании правила 9.**

## Объём

5 книг: 2 в возрастной полосе `3-5`, 3 в полосе `6-8`.
Прогон последовательный, не параллельный: дефекты первой книги должны успеть повлиять
на вторую, иначе мы пять раз повторим одну ошибку.

## Шаги прогона одной книги

| # | Шаг | Выход | Гейт |
|---|---|---|---|
| 1 | Интейк по [intake.md](intake.md) | заполненные Character, Relationship | нет полей «по смыслу» |
| 2 | Подтверждение персонажа | `AppearanceDescriptor` со stableFeatures | подтверждён человеком |
| 3 | StorySpec | арка + список разворотов | `scope.catalog` |
| 4 | Текст | Manuscript по разворотам | `text.authenticity`, `text.factuality`, `text.age_fit` |
| 5 | Иллюстрации | IllustrationSet | `visual.consistency`, `visual.safety` |
| 6 | Сборка превью | полное превью | комплектность |
| 7 | Слепая оценка | оценочный лист | см. ниже |
| 8 | Замеры | строка в отчёте трека | заполнена целиком |
| 9 | Удаление оригиналов | запись в журнале | `privacy.assets` |

Шаг 9 выполняется и на тестовых книгах. Привычка формируется здесь или не формируется
нигде.

## Как меряем консистентность — операционально

«Персонаж узнаваем» — не мнение, а процедура:

1. Трое оценивающих, не участвовавших в производстве книги.
2. Каждому показывают референс героя и один разворот, **без остальной книги**.
3. Вопрос ровно один: **«Это тот же герой?»** — да / нет / сомневаюсь.
4. Разворот засчитан, только если **3 из 3 ответили «да»**. «Сомневаюсь» = не засчитан.
5. Консистентность книги = доля засчитанных разворотов.

Порог 90% (предложение, утверждает владелец — Q2). «Сомневаюсь» приравнено к провалу
намеренно: ребёнок, который сомневается, что это он, — уже проиграл.

## Как меряем попадание в возраст

Трое родителей ребёнка целевой полосы, вслепую:
- прочитали бы это своему ребёнку? да / нет;
- где стало скучно — отметить разворот;
- есть ли слова, которые придётся объяснять.

## Отдельная находка — «текст для мамы»

Гейт `text.authenticity` фиксирует отдельной категорией фрагменты, написанные для того,
чтобы растрогать взрослого, а не увлечь ребёнка. Маркеры: оценочные эпитеты вместо
действия, взгляд со стороны умилённого наблюдателя, финальная мораль, обращение к
чувствам покупателя.

Это не стилистическая придирка. Правило 13 запрещает фальшивый семейный текст, и вот
он выглядит именно так.

## Отчёт по книге

Заполняется целиком, иначе книга не считается прогнанной.

| Поле | Значение |
|---|---|
| № книги, возрастная полоса | |
| Источник изображений | синтетика / сток / материал владельца |
| Консистентность | X из N разворотов (%) |
| Разворотов вернулось после гейтов | N, с причинами |
| Находок «текст для мамы» | N, категории |
| Человеко-минуты: интейк / текст / иллюстрации / редактура | |
| Прочли бы своему ребёнку | X из 3 |
| Оригиналы удалены | дата, запись в журнале |

Человеко-минуты замеряются по каждой книге по факту. Оценка «примерно час» — это не
замер, а самообман, и именно на ней ломается экономика ([unit-economics.md](unit-economics.md)).

## Критерии завершения трека

- консистентность ≥ 90% разворотов в среднем по 5 книгам;
- переделок ≤ 20% разворотов;
- ноль находок «фальшивой теплоты» в финальных версиях;
- человеко-минуты измерены по всем пяти и стабильны.

## Если критерии не выполнены

Порядок действий зафиксирован заранее, чтобы не подгонять его под результат:

1. **Консистентность < 90%** → эскалация Q1 владельцу. Либо меняем толкование
   правила 9, либо детский флагман откладывается. **Снижать порог запрещено.**
2. **Переделки > 20%** → дефект в интейке или StorySpec, а не в генерации.
   Чинится [intake.md](intake.md), трек перезапускается.
3. **Есть «текст для мамы» в финале** → дефект редакционных правил.
   Гейт `text.authenticity` дорабатывается до перезапуска.
4. **Человеко-минуты нестабильны** → процесс не готов к треку A: обещать сроки нельзя.

## Что открывается после трека B

Трек A получает настоящие образцы (только на синтетике или стоке — работы с реальным
ребёнком в маркетинг без отдельного согласия не идут, см. [child-pilot.md](child-pilot.md)).
Трек C остаётся закрытым независимо от результатов: его гейт — реализованная политика
согласий и удаления, а не качество.
