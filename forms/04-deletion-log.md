# Журнал удаления оригиналов

Ведётся с первой тестовой книги. Журнал **не удаляется** вместе с фотографиями
и не содержит самих изображений (правила 8, 10).

Расхождение между «должно быть удалено» и «удалено» — инцидент, а не «поправим потом».

|---|---|---|---|---|---|---|
| | | | | | | |

## Правило срока

Удаление по наступлению **первого** из событий:

1. лист персонажа утверждён + 24 часа;
2. отмена заказа — немедленно;
3. запрос клиента — не позднее 72 часов;
4. TTL с момента загрузки — 90 дней, безусловно.

Пункт 1 действует с D-012: после утверждения листа персонажа производство идёт
от канона и текстового описателя, оригиналы больше не нужны.
