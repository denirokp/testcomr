# Сбор Wordstat — протокол на 10 минут

Открыть [wordstat.yandex.ru](https://wordstat.yandex.ru), войти под любым
аккаунтом Яндекса. Регион: **Россия**. Для каждого запроса записать три числа
в `data/wordstat.csv`, затем запустить `python3 tools/wordstat.py`.

## Три числа, а не одно

| Запись | Что значит | Зачем |
|---|---|---|
| `именная книга` | базовая: все словоформы и любые хвосты | верхняя граница, сильно завышена |
| `"именная книга"` | фразовая: только эти слова в любом порядке | рабочая оценка |
| `"!именная !книга"` | точная: ровно эта форма | нижняя граница, самая честная |

**Без операторов число завышено в разы** — в базовую частотность попадает всё,
включая «именная книга отзывы» и «именная книга своими руками». Планировать
по базовой — классическая ошибка, которая рисует несуществующий рынок.

## Что собирать

### Кластер A — прямой спрос на продукт

```
именная книга
книга с именем ребенка
персонализированная книга
книга про ребенка
сказка про ребенка
книга где ребенок главный герой
книга по фото ребенка
```

### Кластер B — питомцы

```
подарок владельцу собаки
подарок любителю собак
портрет питомца на заказ
книга про собаку
```

**Осторожно с последним.** «Книга про собаку» почти целиком нецелевой запрос:
туда попадают массовые издания о породах и художественная литература. Если базовая
частотность высокая, а точная низкая — это подтверждение, а не спрос.
**Главный индикатор кластера B — «портрет питомца на заказ»**: та же аудитория,
тот же чек, тот же повод. Если там есть объём, наш продукт имеет шанс.

### Кластер C — подарочный интент

```
подарок ребенку на день рождения
подарок на новый год ребенку
необычный подарок ребенку
подарок внуку
подарок крестнику
```

Кластер C нужен не для оценки объёма, а **для сезонности**: именно здесь виден
ноябрьско-декабрьский пик и его точная форма.

### Кластер D — бренды конкурентов

```
сказка ai
именариум
сказки со мной
fairybooks
рикибуки
книга о тебе
```

**Самый недооценённый кластер.** Брендовый спрос — прямой индикатор реального
размера конкурента. Если у крупнейшего игрока 300 запросов в месяц, весь рынок
меньше, чем кажется по обзорам. Если 30 000 — мы недооценили нишу.

### Кластер E — смежный бенчмарк

```
фотокнига
фотокнига на заказ
```

Зрелая соседняя категория с похожей логикой покупки. Служит масштабной линейкой:
во сколько раз наша ниша меньше уже сложившейся.

## Сезонность — отдельно, 2 минуты

В Wordstat переключить на **«История запросов»**, период — **2 года**, для двух
запросов: `именная книга` и `подарок ребенку на день рождения`.

Переписать помесячные значения в `data/wordstat_seasonality.csv`.
Второй запрос — контрольный: он показывает базовую сезонность подарков вообще,
и на его фоне видно, есть ли у нашей ниши **своя** сезонность или она просто
повторяет общий подарочный цикл.

## Дополнительно, если будет время

Регион **Москва** отдельно для кластера A. Доля Москвы в общем объёме — грубая
оценка того, где сосредоточен платёжеспособный спрос. Для продукта за 8–12 тыс. ₽
это важнее, чем общероссийское число.

## Куда вписывать

`data/wordstat.csv` — по строке на запрос:

```
query,cluster,broad,phrase,exact
именная книга,A,0,0,0
```

`data/wordstat_seasonality.csv` — по строке на месяц:

```
month,imennaya_kniga,podarok_rebenku
2024-09,0,0
```

Потом:

```
python3 tools/wordstat.py
```

Скрипт посчитает объёмы по кластерам, индекс сезонности, форму пика и — главное —
**переведёт частотность в прогноз заказов через нашу воронку**. То есть ответит
не «сколько людей ищут», а «сколько книг мы можем продать».
