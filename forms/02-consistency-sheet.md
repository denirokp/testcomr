Остальную книгу видеть не нужно — так и задумано.
Вопрос ровно один. Отвечайте первым впечатлением, не разглядывая.

## Заполняет редактор — не показывать оценивающему

Разворот засчитан только при **3 из 3 «да»**. «Сомневаюсь» = не засчитан.

| Разворот | 3/3 | Категория промаха |
|---|---|---|
| | | лицо не то / костюм / стиль / ракурс / единичный |

**Консистентность книги = `___` из `___` разворотов = `___`%**

Категория «лицо не то»: `___` разворотов.
→ Только это число является аргументом по Q1
([docs/illustration-consistency.md](../docs/illustration-consistency.md)).
Остальные категории — наши процессные ошибки.
